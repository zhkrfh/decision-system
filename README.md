## 理论谱系自述（继承关系声明）

本体系为独立推导，但明确站在以下传统的肩膀上，主动交代以免掠美：

- **凯利公式**（John Kelly, 1956）：仓位思想的原型。公式一 S = p×G − (1−p)×C + 0.3×R×L 是其从赌博赔率向职业决策的改写，p/1.2 修正项来自对过度自信现象（行为经济学）的吸收；
- **前景理论**（Kahneman & Tversky）：v2.1 的损失厌恶系数 λ=2 直接来自其结论；
- **实物期权理论**（Dixit & Pindyck）：κ 系数（平稳期 0.3 / 动荡期 0.5）与"可逆性 R"的定价思想源于此；
- **社会网络与阈值模型**（Granovetter）：三大假设之一"阈值点火"的文献对标；
- **理性疏忽与体制转换**（Gabaix；Hamilton）："突变与伪最大值"假设的文献对标；
- **三不朽传统**（立德立功立言）：终章"身后账户"中 L_名 遗产资产的中国制度对应。

三条"李志恒假设"（阈值点火 / 突变与伪最大值 / 道德抵押）为本体系原创贡献，其推导、对标与边界详见 docs/职业决策体系_定稿包_v1.0.md。

# 五参数计算方式拆解

> 决策体系 · 方法论文档 · 配套《案例01》使用
> 口径：S = p×G − (1−p)×C + 0.3×R×L；资格层（E）参数另见《资格层公式 E 模型设计稿》，本文只拆投入层。
> ⚠️ 口径预告：本文 C 含机会成本，属 v1 口径；v2 差值评估中机会成本被差值结构吸收，届时 C 将重定义为纯下行成本（明面+时间），详见《版本演进_权重侧重分析》。
> 适用前提：机会**确定到手**（资格层参数取固定值后的条件打分）。

---

## 总则：三条铁律

1. **每个参数必须有证据源**——感觉只能提供假设，不能提供分数。找不到证据的参数，默认按最不利档计分。
2. **每个参数先写问题再打分**——分数是答案，问题是靶子。跳过问题直接打分，等于用情绪代替测量。
3. **修正项后置于打分**——先给原始分，再做该参数的规则性修正（如 p÷1.2）。修正必须写进过程，不允许"打分时心里已有数"。

---

## p（成功率）：同岗位的人，几年后达到我想要的状态了吗

**回答的问题**：这条路被走通过吗？走通的人长什么样？

**证据源（按可信度排序）**：
- 一手访谈：该岗位/行业 3–8 年的从业者，直接问"你后悔吗""和你入职时想的一样吗"；
- 半手数据：招聘网站上该岗位的年限—职级要求（晋升通道是否拥挤，看 JD 里"3–5 年经验"岗位存不存在）；
- 公开履历：职场社交平台同岗位人员的晋升轨迹抽样，看中位数而非幸存者。

**锚点（1–10 分）**：
| 分 | 状态 |
|---|---|
| 9–10 | 路径可复制：同岗位前人**普遍**达成我想要的状态，机制清楚 |
| 7–8 | 有可查的成功样本，但需要自己补齐若干条件（语言/资源/时机） |
| 4–6 | 样本稀少或强路径依赖，"有人成但说不清为什么成" |
| 1–3 | 无先例，或成功依赖运气事件（赶上风口、遇到贵人） |

**规则性修正**：原始分 **÷ 1.2**。依据：人对成功率的平均高估约 50%（规划谬误），1.2 是保守截断——不追求精确，只追求系统性压偏。

**常见自欺**：用"行业平均薪资涨幅"代替"我个人达成目标状态的概率"；用幸存者案例（某人做到了）代替中位数。

---

## G（上行收益）：成功时，我带走什么

**回答的问题**：如果 p 兑现，这个岗位让我多出哪些可带走的东西？

**计分三栏（先分栏再合成）**：
- **履历背书**：平台名头在下一个市场的兑换力（离开这个平台后还值多少）；
- **稀缺技能**：离开后市场上供给少、需求在的能力；
- **先发身位**：时间窗口红利（早期市场、新业务线）。

**折扣规则**：兑现周期越长，折扣越重。需要 5 年以上才兑现的收益，按"预期值 × 0.7"计；需要 8 年以上，按 × 0.5。理由：长周期收益的 p 已经在 p 参数里被打过折，这里再折的是"收益本身的缩水"（行业变化、平台衰落）。

**锚点**：10 = 三栏全满且离开平台仍保值；7–8 = 两栏实、一栏虚；4–6 = 只有履历背书（离开即折价）；1–3 = 收益主要是"在里面才有效"的头衔和福利。

**常见自欺**：把平台的能力当成自己的能力（背书≠技能）；把"听起来体面"当成可兑换资产。

---

## C（下行成本）：失败时，我付出什么——**机会成本必填**

**回答的问题**：如果干砸或干得不顺，我损失什么？

**计分三栏（取最高值为主分，次高值每档加 0.5，上限 10）**：
- **明面成本**：金钱投入、异地生活成本、健康损耗；
- **时间成本**：陷进去的年数 × 这几年的市场机会价值；
- **机会成本（必填）**：**我放弃的最优替代是什么，折算成分**。只算"这份工作多苦"不算"我放弃了什么"，是这类打分最常见的自欺。案例01 中 C=7.9 的主要构成，就是"放弃国内银行管培岗"的折算，而不是异国的苦。

**锚点**：10 = 不可逆损失（健康、应届身份烧掉、债务）；7–8 = 烧掉一次性窗口 + 替代机会真实存在且不差；4–6 = 可恢复的时间与金钱损耗；1–3 = 试错成本可忽略。

**常见自欺**：只算苦不算替代（漏机会成本）；把"反正现在也没别的offer"当成替代为零（替代是"下一份能拿到的最好offer"，不是零）。

---

## R（可逆性）：干砸了，能退吗

**回答的问题**：退出时，我带着什么离开、失去什么离开？

**计分两问**：
- **退出摩擦**：随时可离职=高分；有竞业/押金/档案/签证绑定=降分；
- **退出折价**：这段经历在下一市场是否被正确定价？跨境履历回国折价、行业标签锁死（出来只能同行跳）=重降。

**一次性窗口修正**：若该决策消耗不可再生资源（应届身份、落户资格、年龄窗口），在锚点分基础上再降 1–2 分。案例01 的 R=5.1 中，"银行随时可离职"是加分项，"跨境履历回国折价"+"应届身份只有一次"是两个降分项。

**锚点**：10 = 无摩擦无折价随时退出；7–8 = 有摩擦但履历保值；4–6 = 退出有实质折价；1–3 = 退出即行业/身份清零。

---

## L（复利性）：积累的东西，会自己增值吗

**回答的问题**：这个岗位让我攒下的东西，离开后是继续长，还是停在原地？

**区分两类积累**：
- **资产型**：客户网络、可迁移技能、稀缺资质、个人品牌——离开后继续复利；
- **消耗型**：纯执行熟练度、仅限本平台的流程经验、不可迁移的头衔——干十年也只是"更熟"。

**锚点**：10 = 核心产出本身就是资产（作品、客户、方法论）；7–8 = 资产型为主、消耗型为辅；4–6 = 两者相当；1–3 = 纯消耗型，越干越贬值（对市场而言）。

**常见自欺**：把"忙碌"当"积累"——最忙的岗位常常最消耗；把头衔当资产。

---

## 修正规则：R×L 警戒线

**R×L < 10 时，无论 S 多高，仓位封顶轻仓，并加 12 个月止损线。**

原理：R 和 L 都低的岗位是"退出难 + 攒不下"的双重锁死——时间越久，沉没成本越大而资产为零，S 的高分只是延迟到账的亏损。这条规则**先于总分执行**：先查警戒线，再看 S。

---

## 计分流程卡（可印）

1. 写下机会的一句话定义（岗位、地点、入职时间）；
2. p：找证据 → 锚点打原始分 → ÷1.2；
3. G：三栏分列 → 长周期折扣 → 合成；
4. C：三栏分列（机会成本必填）→ 取最高合成；
5. R：两问 + 一次性窗口修正；
6. L：资产型/消耗型判别 → 锚点；
7. 查 R×L 是否 <10（是 → 封顶轻仓 + 止损线）；
8. 代入 S = p×G − (1−p)×C + 0.3×R×L，对刻度读仓位（<0 不打 / 0–20 轻仓 / >20 重仓）；
9. 把五个分数和证据源**存档**——下次复盘对比，这是体系自我校准的唯一途径。

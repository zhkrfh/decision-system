## 一、为什么先做算仓而不是家史

两条候选路径对比：

| | 算仓（95 元/次） | 家史服务（3000 元起） |
|---|---|---|
| 成交难度 | 低（决策类需求普遍存在，交付无实物） | 高（需建立深度信任周期，决策极重） |
| 单次耗时 | ~1.5 小时（含准备） | 4-6 周 |
| 能否重复 | 高（同一人可多次，方法可复用） | 低（每单都是定制） |
| 验证价值 | 直接检验「五参数体系是否真的有用」 | 验证商业模型，但周期太长 |
| 现金速度 | 快 | 慢 |

**结论**：算仓是**最短验证路径**。它同时检验三件事 —— 有人是否需要、体系是否有效、你能否交付。

家史服务作为第二阶段（在有 2-3 个算仓案例后再启动）—— 那时你手里有了可信案例，获客成本会低得多。

## 二、落地页已就绪

`站点/算仓落地页.html` 已生成，包含七段结构：

| 段落 | 作用 | 设计要点 |
|------|------|---------|
| 首屏 | 说清是什么、多少钱、怎么参与 | 「面对一个机会，你该投入多少？」直接用读者原话 |
| 痛点共鸣 | 建立「这说的是我」 | 四条痛点用读者真实困境，不用抽象名词 |
| 五步流程 | 展示方法严谨性 | 每步给出「为什么」，不是只列步骤 |
| 两个档位 | 制造选择而非逼单 | 算分表 69 / 算仓 95，95 标「推荐」 |
| 边界声明 | **信任建设** | 先说四不做，主动邀请打脸 |
| 行动指令 | 降低行动门槛 | 「公众号后台回复算仓」，不加微信 |
| FAQ | 消除最后顾虑 | 四条直击真实疑虑 |

### 关键设计决策

1. **不引导加微信** —— 微信私域引流门槛高、易被封；公众号后台留言是可持续且安全的入口
2. **先讲边界再卖** —— 95 元的价格靠信任支撑，而信任靠「主动说清不做什么」建立
3. **95 而非 99** —— 心理定价，且已在落地页中明确「不会中途加价」
4. **把 1.2 折扣放在第一步** —— 这是体系最有辨识度、最反直觉、最值钱的一条，用于建立专业感

### 3. 首批触达（私域优先）

不依赖算法冷启动。建议 30 人定向名单：

| 来源 | 数量 | 备注 |

| 家人/亲戚 | 5 | 真实需求者，且付费意愿可能更高 |

**话术模板**（避免推销感）：

> 最近在做一件事：把 offer 选择、跳槽、副业这类决策拆成五个数，算完再决定。我写了一套完整方法论在公众号免费公开，现在提供 95 元的一对一完整打分，60 分钟，当场出结论。你如果正好有这类纠结的事，可以找我聊聊，不用买。

### 4. 发布键与收款的账号归属

**关键问题**：收款主体是谁？

- 个人微信收款（有额度与风控限制）
- 公众号赞赏 / 小报童 / 知识星球（平台化，但需开通且抽成）
- 支付宝/银行卡转账（需实名，可能触发风控）

> **建议**：首单用微信收款即可，不要为了一单去做平台化。**先跑通，再合规。** 累计到一定金额后再考虑正规化。

## 四、交付 SOP（首单前必须准备好）

首单交付质量决定了有没有第二单、以及有没有案例可公开。

### 算仓交付清单

**会前**
- [ ] 收集五个参数初值（可用问卷，避免他空想）
- [ ] 准备五步流程卡（发送给他）

**会中 60 分钟**
- [ ] 10 min · 问题定义（把模糊困扰变成可计算的问题）
- [ ] 20 min · 逐参数过（p/G/C/R/L，核对证据源）
- [ [ ] 10 min · p÷1.2 折扣讲解（建立体系认知）
- [ ] 10 min · 计算 S 并解释权重
- [ ] 10 min · 仓位建议与止损条件

**会后 24 小时内**
- [ ] 发送完整复算记录（Markdown/HTML）
- [ ] 登记战绩板（预测 + 验证日期）
- [ ] 询问是否愿意授权公开案例（用于落地页）

### 案例转化路径

```
第 1 单完成
  ↓
征得授权（可匿名）
  ↓
整理为案例稿 → 加入正典仓库案例库
  ↓
用于：落地页信任背书 / 连载素材 / 报价谈判
```

> 每 1 个算仓案例，都是为家史服务（3000-5 万）攒的信任凭证。**这是「先算仓后家史」的真正原因。**

## 五、成功判据

首单结束后检查：

| 判据 | 达标线 |
|------|--------|
| 完成了完整闭环 | 收钱 → 交付 → 对方确认价值 |
| 交付耗时可控 | 会前准备 + 会中 + 会后 ≤ 3 小时 |
| 有案例产出 | 至少 1 个可公开案例（含匿名授权） |
| 有可复制的记录 | 参数表 + S 值 + 仓位建议可直接归档 |
| 对方愿意再来 | 或愿意介绍别人 |

**若未达标**：不要复盘「内容不够好」，而是复盘「哪个环节卡住了没人买单」。

**先说结论：我给一份多数人眼里的"好 offer"打了 1.12 分（满分 10），然后投了。这个分数怎么来的，比结论本身更值得说。**

背景：境外银行客户营销岗，六千公里外，从头开始。家人朋友都觉得"能出去就是赢"。我不反对投——反对的是当时那个"凭感觉算出来的赢面"。

我用的方法很简单，五个数，每个打 1–10 分，然后做一道乘减法：

**S = p×G − (1−p)×C**

- p：成功率。不是"我能不能行"，是"五年后我到达我想要状态"的概率
- G：上行收益。做成了能带走什么
- C：下行成本。失败时失去什么，**必须包含机会成本**（放弃的最优替代）

先说不除 1.2 的原始版本。我的直觉打分：p 给 6.8，G 给 8，C 给 7.9。代入：

S = 0.68×8 − 0.32×7.9 = 5.44 − 2.53 = **2.91**

超过 2，看起来该重仓——直接去就是了。

但 6.8 这个数，我盯着看了很久。它是我的直觉分，而直觉对"自己行不行"这件事，系统性地乐观。所以我给自己加了一条机械纪律：**p 永远先除以 1.2**，没有任何理由，就是对所有自信统一收 20% 的乐观税。

6.8 ÷ 1.2 = 5.67，换算成概率 0.567。重新代入：

S = 0.567×8 − 0.433×7.9 = 4.54 − 3.42 = **1.12**

期望值从 2.91 掉到 1.12，掉掉的全是幻觉的溢价。

1.12 分是什么概念：S 为负不打；0–2 是持有；只有扣掉误差带（±1.5）仍为正的分数才配得上重仓。也就是说，**这次投递在分数上只支持"持有"，不重仓**——它意味着投了，但按兵不动，把主力时间投进别的地方。

你可能会问：那为什么还投？因为分数之外，这项机会还有一个没算进公式的特征：**万一成了，它能带走的东西极多**——履历、跨境经验、完整的金融业务认知。这部分收益很难定价，公式里没位置。我的处理是设一个复核点：两年为期，若这部分"带得走的复利"持续兑现，允许把仓位升一档，但必须写下理由、写下复核时间。

所以整件事的账是：**用 1.12 分的期望，买一张可能升级的门票，同时按兵不动、不押人生。**

这套方法的三个要点，是我认为比"投不投"更重要的：

1. **打分要打在事上，不打在情绪上**。"离家远很可怕"不是分，"放弃现有的一切"折几钱才是分
2. **给自己的自信统一收税**。除以 1.2 不是不自信，是把乐观从本金里抠出来单列
3. **分数只能决定档位，不能代替复核**。世界会变，公式要留复核口

它不是什么万能公式，就是一个把"凭感觉"逼成"记过账"的笨办法。但它治好过我一次：让"我一定能行"变成了一张写着 0.567 的纸。

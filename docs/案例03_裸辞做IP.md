# 裸辞全职做自媒体？我的公式算出来是"别"，但我还是留了一扇门

> 决策体系 · 案例复盘 03 · 基于真实推演（分值经正典仓库核对）
> 转载请署名，非商业使用。
> 口径说明：本文为 v1.8.0 重写版。旧版（+0.3×R×L，S≈27"全靠第三项撑"）已废弃——三项混量纲，提示项不能救负分，详见案例01诚实声明二。

## 题目

要不要裸辞，全职做康复科普 IP？这是我自己推这套公式时面对的第一个真实问题。它有意思的地方在于：旧版公式算出的 S 不低，但结构完全不健康；v1.8.0 口径把这件事说得更直白了——**这道题的期望是深度负值，裸辞全押，不打。**

## 打分

| 参数 | 分值 | 理由 |
|---|---|---|
| p（成功率，修正后） | 2（原始）→ **0.167** | 内容创业的成功率本就低，除以 1.2 后接近地板——这不是不自信，是统计事实 |
| G（上行收益） | **5** | 做成了确实能带走全部：粉丝、作品、声誉、变现能力。但"做成了"是极小概率事件 |
| C（下行成本，含机会成本） | **10** | 顶格。放弃的全部现金流收入 + 简历空窗 + 长期无正反馈的情绪损耗，机会成本按放弃的最优替代计 |
| R（可逆性） | **9** | 唯一的亮色：随时可以停下回到就业市场，内容积累不会一夜蒸发 |
| L（复利性） | **10** | 另一个亮色：作品、粉丝、声誉全是会自己增值的资产，睡后收益 |

## 代入

S = 0.167×5 − 0.833×10 = 0.84 − 8.33 = **−7.5**

## 负期望就是负期望，提示项救不了

−7.5，深度负值，**不打**。裸辞全押这个走法，从期望上就不成立：成功率被砍到地板，而失败的那一端是顶格计价的全套生存成本。

旧版公式曾让这道题得 27 分，全部来自 0.3×R×L——那是把"可逆＋复利"当成了加分项混进总分，量纲都错了。v1.8.0 里 R×L=90 依然很高，但它的角色变了：**它是一个提示项，提示账面 G 和 C 可能大幅低估了跨期复利**——作品和粉丝确实会自己增值，这部分上行没入账。但提示项的权限只有两个：调档、留门。它不能把负期望拉成正，更不能替你把"裸辞"洗成"值得"。

## 留的那扇门：换一道题，而不是改这个分

负的是"裸辞全押"这道题。内容这件事本身，值得换一个 C 口径重新算：**不裸辞，保留现金流主业，每天 1–2 小时业余做**。

业余版重打分：p≈0.167 不变，G=5 不变，C 从 10 降到 1.5——业余时间的机会成本远低于"辞职放弃的一切"，且有现金流托底，简历和情绪都不入风险。代入：

S = 0.167×5 − 0.833×1.5 = 0.84 − 1.25 = **−0.41**

仍略负，但落点在 ±1.5 误差带之内——刻度上这是"持有"档。R×L=90 的高提示在此处才行使它的权限：支持把"持有"升为轻仓长持，理由存档，设复核时间。

**和理财里定投指数同构：不是单次押对，而是低单笔成本＋可持续＋复利，让时间站在你这边。**

一年后重新打分。如果粉丝和作品证明了 p 的上修，业余版会先转正、先加仓——**让证据加仓，不要让热情加仓；裸辞那个版本，等它的 p 自己走到能顶住 C=10 的那天再谈。**

*本案例演示：同一组参数，换一个 C 口径就是换一道题。S 相同的两道题（与案例01 的 1.12、案例02 的 −1.97 对比），内部结构可以天差地别——打分永远要看构成，不要只看总分；提示项只能调档，永远救不了负分。*

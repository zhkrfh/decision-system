# 裸辞全职做自媒体？我的公式算出来是"别"，但我还是留了一扇门

> 决策体系 · 案例复盘 03 · 基于真实推演（分值经正典仓库核对）
> 转载请署名，非商业使用。

## 题目

要不要裸辞，全职做康复科普 IP？这是我自己推这套公式时面对的第一个真实问题。它有意思的地方在于：算出来的 S 不低，但**结构完全不健康**。

## 打分

| 参数 | 分值 | 理由 |
|---|---|---|
| p（成功率，修正后） | 2（原始）→ **1.67** | 内容创业的成功率本就低，除以 1.2 后接近地板——这不是不自信，是统计事实 |
| G（上行收益） | **5** | 做成了确实能带走全部：粉丝、作品、声誉、变现能力。但"做成了"是极小概率事件 |
| C（下行成本，含机会成本） | **10** | 顶格。放弃的全部现金流收入 + 简历空窗 + 长期无正反馈的情绪损耗，机会成本按放弃的最优替代计 |
| R（可逆性） | **9** | 唯一的亮色：随时可以停下回到就业市场，内容积累不会一夜蒸发 |
| L（复利性） | **10** | 另一个亮色：作品、粉丝、声誉全是会自己增值的资产，睡后收益 |

## 代入

S = 1.67×5 − 0.833×10 + 0.3×9×10 = 8.35 − 8.33 + 27 ≈ **27**

## 结构比总分重要：期望为负，全靠复利撑

拆开看：**p×G − (1−p)×C ≈ 0，甚至是负的**——期望收益根本不成立。27 分几乎全部来自第三项 0.3×R×L=27，即"可逆 + 复利"这两根柱子。

这类结构最经典的误读是："分数不低，干！"——错。分数高只说明**这条路值得用便宜的方式走**，不说明值得押上全部。期望收益为负的生意，正确的姿势是用零成本期权的方式参与，而不是 all in。

## 我的决定

保留现金流主业，每天 1–2 小时轻仓长持做内容。R×L 高的东西，最适合的就是"用不影响生存的额度持续定投"——和理财里买指数的逻辑同构：单次看不清，但正期望 + 可持续 + 复利，时间会站在你这边。

一年后重新打分。如果粉丝和作品证明了 p 的上修，再讨论加仓——**让证据加仓，不要让热情加仓。**

*本案例演示：S 相同的两道题（与案例一的 52.6、案例二的 27.4 对比），内部结构可以天差地别。打分永远要看三项的构成，不要只看总分。*

# 公众号发布操作规程（v1.0）

> 适用：账号「臧亥奎荣」的图文发布。经 2026-10-04 实战验证后沉淀。
> 核心结论：浏览器模拟操作（execute_script 级）**不可靠**——样式会被剥、保存会静默失败。放弃该路径。

## 背景知识（检索自官方文档与实战）

1. 公众号编辑器（ProseMirror 内核）对**非可信粘贴事件**（脚本合成的 ClipboardEvent）会剥离样式甚至静默丢弃；
2. 第三方编辑器（135/壹伴）能用，靠的是真人粘贴（可信事件）或官方 API 同步；
3. **官方草稿 API `draft_add` 存在**（POST api.weixin.qq.com/cgi-bin/draft/add）：服务端调用、需 AppID + AppSecret 换 access_token，可直接把 HTML 正文写入草稿箱——这是唯一可靠的全自动路径；
4. 草稿 API 注意：title ≤32 字、author ≤16 字、content 支持 HTML 但**图片必须是微信永久素材 media_id**（外链图会被过滤）、封面 thumb_media_id 必填（可用微信默认图或不传看接口容忍度）。

## 三条发布路径（按优先级）

### 路径 A：用户手动粘贴（默认路径，最稳）
1. 我产出素材 HTML（内联样式版，如素材1/2）；
2. 用户双击打开 → 全选复制 → 粘贴进公众号编辑器（真人粘贴，样式保留）；
3. 填标题/摘要 → 预览 → 用户亲自点群发。
- 我的责任边界：素材排版、标题摘要文案、发布后回填仓库台账。

### 路径 B：官方 API（全自动，需凭据）
1. 用户提供 AppID + AppSecret（设置与开发→基本配置，IP 白名单需含执行机）；
2. 流程：get_access_token →（如需）上传永久图片素材 → draft_add；
3. 凭据只写入本地 `.env`（gitignore），任何输出/日志不得含 secret；
4. 适合：连载批量化（12 章逐章进草稿箱，用户只审不发）。

### 路径 C：浏览器自动化（已弃用）
仅用于查看后台数据（草稿箱列表、发表记录），**不用于写内容**。教训：两次完整保存循环均未落库，样式剥离无法绕过。

## 标准发布流程（合并 SOP）

1. 内容定稿（正文 MD + 素材 HTML，过《决策体系发布SOP》检查）；
2. 按路径 A 或 B 进入草稿箱；
3. 用户预览 + 亲自群发（发布键永不代按）；
4. 我回填：正典仓库"发布记录"节 + 记忆页更新。

## 常见错误台账

| 错误 | 原因 | 对策 |
|---|---|---|
| 保存后草稿箱为空 | 标题写入的元素不对 / 合成事件不可信 | 弃浏览器写内容，走路径 A/B |
| 粘贴样式丢失 | ProseMirror 剥离非可信事件样式 | 真人粘贴或 API 传 HTML |
| 后台会话过期快 | 扫码登录态短 | 扫码后立即操作；导航最小化 |
| 草稿 API 图片报错 | 用了外链图 | 先传永久素材拿 media_id |

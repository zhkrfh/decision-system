# 月薪两万的 996，为什么我只给轻仓

> 决策体系 · 案例复盘 02 · 基于真实推演（分值经正典仓库核对）
> 转载请署名，非商业使用。

## 题目

一个具体的岗位：某大厂核心业务线，月薪约两万，但标准工时 996，业务处于平台期，晋升靠排队。直觉上这是"好工作"——钱多、平台大、说出去体面。

用公式算完，它只值一个轻仓。

## 打分

| 参数 | 分值 | 理由 |
|---|---|---|
| p（成功率，修正后） | 4.9 原始 → **4.08** | 同岗位五年后达到"我想要的状态"的比例，除以 1.2 后缩水明显：晋升排队不是个人能努力的变量 |
| G（上行收益） | **7.5** | 薪资高、履历硬，但可带走的客户与作品积累有限——平台的东西终究是平台的 |
| C（下行成本，含机会成本） | **8.5** | 健康损耗、时间全部交给体系、放弃的其他可能性；机会成本按放弃的最优替代折算，必填 |
| R（可逆性） | **3** | 随时能辞职，但连续 996 三年后"退回市场"的身位明显下沉；技能标签开始锁死 |
| L（复利性） | **2** | 纯重复执行型岗位，攒下的东西几乎不自己增值 |

## 代入

S = 4.08×7.5 − 0.592×8.5 + 0.3×3×2 = 30.6 − 5.03 + 1.8 = **27.4**

## 关键：总分是假的，规则是真的

27.4 > 20，按总分这是"重仓"。但打分纪律里有一条**修正规则**：当 R×L < 10 时，无论 S 多少，最高只能轻仓，且设 12 个月止损线。

这题 R×L = 3×2 = 6，触发。

直觉的错位就在这里：S 高是因为 G（月薪）撑起来的，但 G 是**租来的**——干一天有一天，走的那天一分带不走。而 R×L 度量的是"这份工作在你身上留下了什么"。留下的是消耗，不是资产，那它就是一间月租很贵的房子：付得起可以住，但绝不装修，也绝不托付终身。

## 结论与止损线

轻仓进入，同时写下一行字贴在显眼处：**12 个月后重新打分，若 C 上升或 R 继续下降，无条件清仓。**消耗型岗位最危险的不是进入，是温水——所以止损线必须在情绪最好的时候写下来。

*本案例同时演示两条纪律：p 永远除以 1.2；先查 R×L，再看总分。*

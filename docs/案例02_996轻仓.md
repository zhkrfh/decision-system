# 月薪两万的 996，为什么我连轻仓都不给

> 决策体系 · 案例复盘 02 · 基于真实推演（分值经正典仓库核对）
> 转载请署名，非商业使用。
> 口径说明：本文为 v1.8.0 重写版。旧版（+0.3×R×L，S=27.4"限轻仓"）已废弃——三项混量纲，第三项不能加分，详见案例01诚实声明二。

## 题目

一个具体的岗位：某大厂核心业务线，月薪约两万，但标准工时 996，业务处于平台期，晋升靠排队。直觉上这是"好工作"——钱多、平台大、说出去体面。

用公式算完，它连轻仓都拿不到：**期望是负的**。

## 打分

| 参数 | 分值 | 理由 |
|---|---|---|
| p（成功率，修正后） | 0.49 原始 → **0.408** | 同岗位五年后达到"我想要的状态"的比例，除以 1.2 后缩水明显：晋升排队不是个人能努力的变量 |
| G（上行收益） | **7.5** | 薪资高、履历硬，但可带走的客户与作品积累有限——平台的东西终究是平台的 |
| C（下行成本，含机会成本） | **8.5** | 健康损耗、时间全部交给体系、放弃的其他可能性；机会成本按放弃的最优替代折算，必填 |
| R（可逆性） | **3** | 随时能辞职，但连续 996 三年后"退回市场"的身位明显下沉；技能标签开始锁死 |
| L（复利性） | **2** | 纯重复执行型岗位，攒下的东西几乎不自己增值 |

## 代入

S = 0.408×7.5 − 0.592×8.5 = 3.06 − 5.03 = **−1.97**

## 关键：赢面是租来的，代价是全额的

−1.97，落在刻度负半区，**不打**——连"持有"的资格都够不上。

直觉的错位拆开看很清楚：这项机会看起来"收益高"，是因为 G（月薪 7.5）够亮眼。但 p 只有 0.408——晋升排队这条路，五年后大概率到不了你想要的位置。于是第一项被概率砍掉一半还多，只剩 3.06；而失败的那一端是全额计价的：996 的时间、健康的损耗、放弃的其他可能性，0.592×8.5 = 5.03，一分没少。

**G 是租来的**——干一天有一天，走的那天一分带不走；**C 是全额的**——你交出去的时间与健康，一天都收不回。一租一全，期望自然转负。

再补一刀：R×L = 3×2 = 6，触发警戒线。这意味着即便未来重打分让 S 转正（比如 p 修正、C 下降），这个局最高也只能轻仓＋12 个月止损——因为 R×L 度量的是"这份工作在你身上留下了什么"。留下的是消耗，不是资产，那它就是一间月租很贵的房子：付得起可以短住，但绝不装修，也绝不托付终身。

## 结论

**不打。** 不是"谨慎进入"，是不进入。

留一条复核口：12 个月后若岗位性质变化（平台期结束、职级结构改革），重新打分。但注意——复核时先看的仍是 R×L：消耗型岗位的 R 和 L 只会随时间下降，警戒线大概率越拉越紧。这个局最可能的终局不是"转正"，是"更不值得"。

*本案例演示两条纪律：p 永远除以 1.2；负期望不打，提示项救不了负分——R×L 只是调仓提示，不是加分项。*

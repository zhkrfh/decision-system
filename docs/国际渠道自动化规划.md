# 国际渠道自动化规划（v1.0，2026-10-06）

> 原则（李志恒定调）：做市场的内容杠杆不限于国内，**凡是有 API、可实现全自动的杠杆都建**。执行成本继续向"你只授权，我全程操作"压缩。

## 一、国际平台 API 可用性矩阵

| 平台 | API | 自动化程度 | 受众匹配 | 优先级 |
|------|-----|-----------|---------|--------|
| **Telegram 频道** | Bot API，全开放 | ★★★ 全自动 | 海外华人/决策话题社群，可做私域广播 | P0 |
| **Bluesky** | AT Protocol 全开放 | ★★★ 全自动 | 英语职场/理性讨论社区 | P0 |
| **Mastodon** | 全开放 | ★★★ 全自动 | 英语技术/理性人群 | P1 |
| **dev.to** | 官方文章 API | ★★★ 全自动 | 长文好去处；凯利/量化话题有受众 | P1 |
| **Medium** | 官方 API（受限但可用） | ★★☆ | 英语长文，SEO 强 | P2 |
| **RSS（独立站）** | 无需账号 | ★★★ 全自动 | 一切阅读器的入口，搜索引擎抓取 | P0（零成本） |
| X/Twitter | API 收费贵 | ★☆☆ | 有钱再上 | 暂缓 |
| LinkedIn | API 严格限定 | ★☆☆ | 需企业身份 | 暂缓 |
| Reddit | API 有配额+社区文化敏感 | ★☆☆ | 先手动观察 | 暂缓 |

## 二、内容策略：英文版轻改写

- 语言：英语（触达全球"career decision"受众），源内容仍是中文正典
- 形态：短帖（Telegram/Bluesky/Mastodon，150–250 词）+ 长文（dev.to/Medium，知乎体英文版）
- 定位关键词：career decisions, Kelly criterion for life choices, offer evaluation, quitting your job
- 合规：同样"零硬广"，署名链接放 bio

## 三、分发台扩展（dispatcher v0.2）

新增命令：
```
python tools/dispatcher.py post telegram <标题> <正文文件>   # Bot API 发频道
python tools/dispatcher.py post bluesky <标题> <正文文件>    # AT Protocol 发帖
python tools/dispatcher.py post devto  <标题> <正文文件>     # 官方文章 API
```
凭据全部进 .env（不入 git）：
- TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID
- BLUESKY_HANDLE + BLUESKY_APP_PASSWORD
- DEVTO_API_KEY

## 四、你需要做的授权（各 ~2 分钟）

1. **Telegram**：找 @BotFather → /newbot 取名 → 拿 token 发我；再把 bot 拉进你建的新频道并设为管理员（我自动取 chat_id）
2. **Bluesky**：bsky.app 注册（用户名建议 canghakuirong 或 juecejue）→ Settings → App Passwords 生成一个发我
3. **dev.to**：注册（可用 GitHub 登录）→ Settings → Extensions → DEV Community API Keys 生成发我

三个都给齐后，一篇中文内容的全渠道矩阵 = 公众号（自动）+ 独立站（自动）+ RSS（自动）+ Telegram/Bluesky/dev.to（**一条命令全自动**）。

## 五、节奏与风控

- 国际端每周 2–3 帖，从正典内容轻改写，不新增写作负担
- 各平台新号同样有信任期：前 2 周低频（每周 1 帖）养号，避免被标记 spam
- 全部平台 bio 统一：方法论简介 + 独立站链接，**零硬广**（国际平台对导流更敏感）

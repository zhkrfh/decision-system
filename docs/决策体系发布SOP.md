# 决策体系公开发布 · 执行 SOP

> 适用范围：决策课程/职业决策体系的全部公开内容（公众号、正典仓库、案例、声明、挑战者悬赏）。
> 原则：本 SOP 是发布质量门，不是创意限制。任何一篇内容不通过本 SOP 检查，不发布。
> 体系状态：理论已冻结（v1–终章，止步声明生效），本 SOP 只管"应用与发布"。

## 0. 身份与署名规则

- 思想发表身份：待定（实名 / 固定第三笔名），**与网文笔名"烧心"严格分离**（决策项，见待办）；
- 所有发布物统一署名 + 版本号（如 `体系正文 v1.0, 2026-10`）；
- 转载许可：署名 + 非商业（CC BY-NC 类），声明放每篇文末固定位置。

## 1. 内容分层与发布顺序（不可调换）

| 顺序 | 层 | 内容 | 禁忌 |
|---|---|---|---|
| 1 | 正典层 | 正典仓库（版本化存证 + 理论谱系自述） | 不含任何情绪化表述 |
| 2 | 边界层 | 《我不度量什么》《体系不解决什么》 | 先于一切体系正文发布 |
| 3 | 工具层 | 算分表（含存续条件硬拦截） | 表格必须先于任何案例发布 |
| 4 | 案例层 | 4 个冷启动打分案例 | 只用已发生、已验证的案例 |
| 5 | 体系层 | v1–v4 通俗版连载 | 不碰 v5.1/终章 |
| 6 | 深水层 | 道德三部曲（v5.1、终章）| 最后发、成对发、长文体裁、不拆条、不上短视频平台 |

## 2. 单篇发布流程（每篇都走）

1. **选题核对**：对照内容分层表确认允许发布；
2. **写作**：正文同一份 Markdown 源，先入正典仓库，再改平台版本；
3. **术语检查**（对照清单 A）；
4. **边界句检查**：凡量化道德/生命/自由处，同一屏内必须有边界句；
5. **案例核验**：数字前后一致、时间线可交叉核对（参照家史 SOP 的核验纪律）；
6. **冷却**：成稿后隔 24 小时再发布（防冲动表述）；
7. **发布后**：链接回填正典仓库"发布记录"节。

## 3. 检查清单 A：术语防弹

- [ ] 无"押命""拿命换钱""标价人命"类口语化表述 → 一律用"存续阈值约束""不可逆成本过滤""存续条件"
- [ ] "道德抵押/违约净值"出现处，必带上下文：度量对象是**信誉与承诺的经济学**，不是道德本身的价值
- [ ] "0/1 阈值过滤器"表述完整出现，不可省略为"算进去"
- [ ] 通读假设读者只截取文章最刺眼的一句话发到微博——那句话是否站得住？

## 4. 互动纪律

- 不逐条回复情绪性攻击；每月集中一篇《常见误解澄清》；
- 挑战者悬赏三条款：只收带真实决策案例的失效报告 / 每季集中评审 / 评审结论不构成对话义务；
- 一对一算仓（99 元/次）：涉自杀、极端决策一律不接并附心理援助提示；不含反复追问；
- 预设情绪预算：30% 读者误读、10% 恶意曲解属正常态，不按"讲道理会赢"预算。

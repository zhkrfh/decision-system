# 冷启动专项：四周内容实验方案 v1.0

> 生成时间：2026-10-10
> 依据：`docs/项目目的自述与风险评估_v1.0.md` 的 P0 建议
> 核心问题：曝光 75 / 阅读 5 / **点赞 0 / 收藏 0** / 公众号涨粉 1 —— 管线跑通了，管道对着空房间
> 原则：**暂停基建，专攻内容与传播**

---

## 一、实验设计

### 核心假设

> 冷启动期的瓶颈不在「发得不够快」，而在「没人点开、点开也没留下」。

因此本周期**只验证三个变量**，不动其他：

| 变量 | 对应环节 | 具体测什么 |
|------|---------|-----------|
| A · 标题 | 决定是否被点开 | 场景化标题 vs 术语标题 |
| B · 前 200 字 | 决定是否读完 | 钩子类型（真实分数 / 反常结论 / 具体困境） |
| C · 标签与选题 | 决定是否进推荐池 | 泛理财话题 vs 精准人群（应届/跳槽/裸辞） |

### 为什么砍掉其他变量

四周内同时测标题、封面、发布时间、平台、选题五项，结果是**哪项都归因不清**。锁定三项，其余全部固定不动。

---

## 二、每周动作

### 周一 · 选题与钩子设计

- 从知乎热榜 + 垂直搜索产出 5 个候选选题（自动化：`python tools/dispatcher.py zh-scout`）
- 按「先窄后宽」原则过滤：只保留**面向应届生 / 跳槽 / 裸辞 / 仓位决策**的场景
- 每个选题写出 A/B 两个标题版本，标注假设（例：场景化 vs 术语化）
- 交作者拍板：只答「做 / 不做 + 选 A / 选 B」

### 周二 · 正文撰写与复算

- 按理论图谱口径写作，**每个数字必须可复算**
- 连载 05-10 期间，每篇至少含 1 个新案例或已有案例的新角度
- 前 200 字按 B 变量要求撰写，开头禁止以定义或理论起笔

### 周四 · 跨平台复算与修正

- 汇总本周两篇的曝光/阅读/点赞/收藏/涨粉 → `metrics.csv`
- 对比 A/B 标题的表现，**记录哪个假设成立**
- 每周只调整一个变量，其余保持稳定

### 周六 · 复盘（关键，不可跳过）

回答三个问题，答案写进 `docs/选题侦察_YYYYMMDD.md`：

1. 哪个标题版本带来了更多阅读？（验证 A）
2. 哪种开头让读者读完了？（验证 B）
3. 哪个选题进池了、哪个没有？（验证 C）

> **纪律**：四周内不改基建、不加平台、不做新工具。任何「顺手优化一下」的冲动都要记下来，延到周期结束后统一处理。

## 三、成功判据（第 4 周末评估）

不设增长数字目标，**只验证方法是否成立**：

| 判据 | 说明 |
|------|------|
| 至少 1 个变量被证实 | 三项中至少一项找到稳定有效的做法 |
| 点赞/收藏不再是 0 | 证明内容有留人价值，而不只是被曝光 |
| 单篇阅读量翻倍 | 相对当前基线（公众号 1 涨粉 / 小红书 5 阅读） |

**若三项均未改善**：说明问题不在标题与钩子，而在选题方向或人设本身，需要重新评估定位——这是有价值的结论，不是失败。

---

## 四、这四周不做的事

| 不做 | 理由 |
|------|------|
| 新增平台（B站/抖音/视频号） | 分散精力，且当前单平台都未验证 |
| 开发新工具 / 优化 dispatcher | 管线已够用；`metrics.csv` 的瓶颈是数据本身 |
| 知识星球 / 小报童开通 | 无订阅者，开通即空转 |
| 算分表上架 | 冷启动期不挂产品（连载大纲 v2 约束 5） |
| 扩写连载 06-10 | 先有 3 个验证样本，再谈体系完备 |

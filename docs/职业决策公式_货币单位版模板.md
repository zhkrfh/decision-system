# 职业决策公式 · 货币单位版完整模板（v2.1）

> 职业凯利公式：用真金白银为单位的精力仓位决策工具
> 版本：v2.1（货币单位版）｜适用：岗位选择、副业投入、转行评估、机会排序

---

## 一、公式总览

### 核心公式

$$f^* = \frac{S}{W}$$

- **f\***：该机会应投入的精力仓位（%，与凯利公式同构）
- **S**：该机会的期望净收益（单位：元/年，含期权价值）
- **W**：你的人力资本总市值（单位：元，全局锚点）

### S 的完整表达式

$$S = p_E \cdot p_I \cdot G \;-\; \lambda \cdot (1-p) \cdot C \;+\; \kappa \cdot R \cdot L \cdot G \;+\; c\sqrt{\frac{\ln t}{n_i}} \cdot G$$

| 项 | 名称 | 单位 | 来源理论 |
|---|---|---|---|
| p_E · p_I · G | 期望收益 | 元/年 | Vroom 期望理论 + 期望效用 |
| λ(1−p)·C | 期望损耗（损失厌恶加权） | 元/年 | 前景理论 |
| κ·R·L·G | 期权价值 | 元/年 | 实物期权理论 |
| 探索加成项 | 试错期权 | 元/年 | 多臂老虎机 UCB |

## 二、全局锚点：W（人力资本总市值）

**每年重算一次**，重大跃迁后立即重算。

$$W = \text{流动存款} + \sum_{i=1}^{N} \frac{\text{预期年收入}_i}{(1+r)^i}$$

简化版（r 取 0-3%，保守可用 r=0 直接加总）：

```
W = 当前存款 + 剩余工作年限 × 当前或预期年均收入
```

示例：25 岁，存款 5 万，预期年均收入 15 万，工作年限 35 年，r=0：
**W = 5 万 + 35 × 15 万 = 530 万元**

> 意义：W 越大，单个机会占仓位越小 → 数学上呈现"越有积累，越输得起，越应该探索"的反脆弱结构。

## 三、参数折算表（全部折算为 元/年）

### G：上行收益（成功时每年带走什么）

| 项目 | 折算方法 | 示例 |
|---|---|---|
| 薪资增量 | (新岗位年收入 − 当前/替代岗位年收入) | 15万 − 9万 = +6万 |
| 技能溢价 | 该技能未来每年可多挣的钱（保守估） | 销售能力年溢价 +1万 |
| 客户/人脉资源 | 这些资源未来每年能变现的钱的保守估计 | +0.5万 |
| 作品/履历价值 | 对下一份工作薪资的抬升幅度 | +0.5万 |
| 时间盈余 | 每年少干的通勤/加班小时 × 你的时薪 | −1000h×30元 = +3万（时间也是钱） |

**G = 各项加总**（只算能带走的；带不走的福利不算）

### C：下行成本（失败/过程中每年损耗什么，λ=2 前置系数后乘）

| 项目 | 折算方法（影子价格法） |
|---|---|
| 机会成本 | 放弃的最优替代选择的年收益（**最常漏项，必填**） |
| 情绪损耗 | 问自己："每月给我补 X 元，我愿意承受这种痛苦吗？"——X×12 即年成本 |
| 时间损耗 | 加班/通勤超出基线的小时数 × 时薪 |
| 健康损耗 | 预估未来因此多花的医疗/健身支出 |
| 退出折价 | 若干砸，履历受损导致的下份工作薪资降幅 × 预期影响年限 |

**C = 各项加总**；代入公式时乘 **λ = 2**（损失厌恶系数：亏 1 万的痛 ≈ 赚 2 万的快乐）

### p：成功率（拆成两段，防止高估）

| 子参数 | 问题 | 修正 |
|---|---|---|
| p_E（能干成） | 以我的能力，做出成绩的概率 | 打分后 × 0.8（自我高估修正） |
| p_I（能兑现） | 干成后承诺的回报真能兑现吗 | 看该组织历史兑现记录；画饼组织打 0.5 以下 |
| p = p_E × p_I | | |

### R / L / κ：期权项（无量纲）

| 参数 | 含义 | 打分参考 |
|---|---|---|
| R 可逆性 | 干砸了退出容易吗 | 能随时离职=0.9；有服务期=0.5；行业标签锁死=0.2 |
| L 复利性 | 积累会自己增值吗 | 攒客户/作品/声誉=0.8；重复劳动=0.2 |
| κ 期权系数 | 随环境不确定性调节 | 平稳期 0.3；行业动荡（AI 冲击等）0.5 |

### 探索加成（UCB 项，可选）

```
加成 = c × √(ln t / n_i) × G
```
- t = 你剩余的职业尝试轮数（粗略：剩余年数 ÷ 2，按 2 年一档）
- n_i = 你在该方向已投入过的档数（没试过=1）
- c = 探索系数，年轻（<30 岁）取 0.3，年长取 0.1
- **直觉**：没试过的方向有"好奇心加成"，年轻时加成更高——支持多探索

## 四、f* 仓位对照表

| f* | 决策 | 附加规则 |
|---|---|---|
| ≥ 100% | 数学允许全押 | **强制封顶 80%**（人非机器，留修复层） |
| 40-80% | 主力仓位，认真投入 | 守住业余资产层 |
| 10-40% | 兼职试水 | 定期（6 个月）贝叶斯更新重算 |
| < 10% | 低于最小有效剂量 | 不投——精力切换有成本，撒胡椒面=没投 |

**两条组合规则（叠加于 f* 之上）**：
1. **哑铃规则**：整体组合必须同时含"安全端"（稳定现金流）和"投机端"（高风险高上行）。中间态岗位（普通公司的普通岗）S 打 8 折
2. **相关折价**：与现有主业同风险因子的机会，G 打 8 折（相关性高 = 没有分散价值）

**止损规则**：R×L < 0.3 的仓位，无论 f* 多少，最高轻仓（≤40%），且设 12 个月止损线。

## 六、验证案例（工银泰国岗，2026-10）

- 假设：月支出 3000，预期收入增量 6 万/年，技能+人脉+履历 +2 万/年 → G = 8 万
- 成本：境外损耗+情绪约 2 万/年 → C = 2 万
- p_E = 0.6×0.8 = 0.48；p_I = 0.9 → p = 0.43；λ=2
- R=0.7, L=0.6, κ=0.3 → 期权项 = 0.3×0.7×0.6×8万 ≈ 1.0 万
- **S = 0.43×8 − 2×0.57×2 + 1.0 = 3.44 − 2.28 + 1.0 = 2.16 万/年**
- W ≈ 500 万 → **f* = 0.43%**

**解读**：单看 f* 很小（人力资本基数大），但这是"主力职业级"机会，应占职业精力的主力仓位（40-80%）而非字面 0.43%——**f* 用于同量级机会之间的相对排序和上限约束**，同 rank 机会按 f* 比例分配精力。此为该框架的已知局限：跨量级比较时以 rank 分层为准。

## 七、使用纪律

1. 所有影子价格当场自问自答，写下来，事后可审计
2. 机会成本必填——最常漏、影响最大的一项
3. 打完分 6 个月后用实际数据回测：偏差 >30% 就修参数
4. f* 是排序与上限工具，不是精确答案；决策瓶颈时叠加"最小后悔法"（80 岁视角：哪种选法不后悔）
5. 每 6 个月贝叶斯更新一次 p 和 G；W 每年重算

# 算出来是负数的那天，我谢绝了一场"家族事业"

> 决策体系 · 案例复盘 04 · 基于真实推演（人物信息已匿名化）
> 转载请署名，非商业使用。

## 题目

亲友介绍的"机会"：加入一个熟人盘的保险/直销类团队，话术是现成的——"自己人带你""时间是自由的""上不封顶"。这类邀约的可怕之处在于它绑架人情：拒绝像是不给面子。

这次不用纠结，公式只用了五分钟。

## 打分

| 参数 | 分值 | 理由 |
|---|---|---|
| p（成功率，修正后） | 1.7 → **1.42** | 真实收入分布极度头部化，"上不封顶"的另一个名字是"绝大多数在底部"；除以 1.2 后几乎归零 |
| G（上行收益） | **3** | 做成者带走的是人脉透支后的残余，不可复用 |
| C（下行成本，含机会成本） | **8** | 时间、熟人关系的不可逆损耗（这一项最贵）、错过正常职业积累的窗口 |
| R（可逆性） | **2** | 名义上"随时退出"，实际上人情债已经预付——退出成本远高于入职成本 |
| L（复利性） | **3** | 攒下的不是客户信任，是通讯录里的避雷标记 |

## 代入

S = 1.42×3 − 0.858×8 + 0.3×2×3 = 4.25 − 6.87 + 1.8 = **−0.8**

## 两个红灯同时亮

**S ≤ 0：清仓**——这是唯一一个结论本身就是"不要开始"的区间，连试的必要性都没有。

**R×L = 6 < 10：双重确认**——即便总分是正的，这类"看似自由、实则预付人情债"的结构也只配轻仓。两项检查指向同一个答案时，决策不再需要勇气，只需要执行。

## 关于拒绝的经济学

拒绝的难点从来不是算不清账，而是人情压力。但把账摊开反而让拒绝变得体面："我算过这笔账，期望是负的，而且退出的成本比进入高——不是不给你面子，是这套结构对绝大多数加入者不成立。"用结构代替态度，就事论事，不评判对方的动机——对方反而更容易接受。

公式在这里的第二重价值显现：**它不只是决策工具，还是拒绝的话术结构。**

*本案例演示：S ≤ 0 区间的处理——不纠结、不试错、不解释第二遍。清仓决策省下的时间，才是公式真正的回报。*

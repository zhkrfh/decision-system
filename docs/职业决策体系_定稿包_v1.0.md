## 二、体系最终结构（六层收束）

```
计算层（可算）：
  v4  S_市场 = W(1−d)(1−g…) − w·h        五观测值，市场端定价
  v5  S = α·S_市场 + (1−α)·S_个人         双通道博弈，α 查表+事后校准
      f* = S ÷ (w×2000×T)                精力仓位（凯利同构）

解读层（不可算，校准用）：
  v5.1  道德入局：信义→d、贪嗔痴→λ/p、以身入局→F 杠杆
  终章  γ·L_名：身后账户，结算日在死后，随传说复利
  信息场：无"市场"客体，只有 N 个接收面投影；α=对投影的信任度
  行动阈值（李志恒假设①②）：S* 点火机制 + ΔS^ex 突变致伪最大值
  道德抵押定价（李志恒假设③）：违约净值 = ΣR_t折现 − P(曝光)·Δd·W_剩余·λ
```

**两条实操主线**（全部推演的最终收口）：
1. 日常评估用 v4/v5 出数；人生级不可逆决策叠加最小后悔法
2. 不求预测突变（慢变量），求缩短伪值存活期——定期重算 + 校准参数带有效期标签

## 三、三条原创假设（李志恒假设，与文献的关系已对标）

**假设①（阈值点火）**：个体仅当 S 越过私人阈值 S* 才行动并产生信息。
——对标：Dixit-Pindyck 触发边界、Granovetter 阈值分布。**经西蒙有限理性修正：S* 应为"满意阈值"而非"最大值阈值"（satisficing）。**

**假设②（突变与伪最大值）**：非投影场因素（ΔS^ex）介入使实际值突变，先前计算值沦为伪最大值。
——对标：Gabaix 理性疏忽（忽略慢变量是理性的）、Hamilton 体制转换（全体估计集体作伪）。关键细分：ΔS^ex = 噪声 + 慢变量，致命的是后者（十年尺度：技术范式/人口/监管/健康资本）。

**假设③（道德抵押）**：人在某些条件下将道德乃至生命作为抵押品。
——对标：西方仅零散描述（遗赠动机/荣誉文化/存在主义，无形式化）；中国传统有完整制度对应（儒家信用质押、纵横家人格抵押、三不朽三类身后资产、史官=审计、谥号=评级、汗青=永不违约的账本）。量化：违约净值公式（见上），核心结论——抵押品是 d×W_剩余，故"越有前途者违约越亏"，违约者分布是 W_剩余×P(曝光) 的分布，非道德分布。**空白点：γ·L_名 的形式化全球无人认领；中国传统的"账本权威性决定抵押行为发生率"假说（γ 衰退根源=传统账本权威崩塌而新账本公信未立）。**

**假设的组合推论**：信息场只由触发者构成（S≥S* 者发声）→ 观测场天然是截断样本；市场底部最缺信息、顶部信息过剩——**场的信噪比与真实机会负相关**。

## 五、明示的边界（防止误用）

1. **信息场整体不可计算**（参数自指、ε 不可观测、联合解不可约）——它产出定向修正/证伪追问/类比警觉，不产出数字
2. **f* 除以人力资本市值后占比极小**——用于同量级机会排序，跨量级按档位判断
3. **纯利益模型对"最后一单博弈"失灵**（W_剩余≈0 者违约划算）——需制度（刑罚/征信）人为修复负值区间
4. **γ、β 为纯私人参数**——本人也只能在决策瞬间揭示，模型对其估值永远粗糙

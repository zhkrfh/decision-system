## 验证登记规则

1. 预测必须在**发布时**写死（本页+文章内），禁止事后修改口径；
2. 结果分三档：命中 / 未命中 / 无法判定（信息不足）——不允许"基本命中"；
3. 未命中不删除记录，写入当天日期与原因分析，链接进对应案例的"复盘"段；
4. 连续 3 条预测后做一次"预测校准率"小结（命中数/总数），作为 p 修正系数 1.2 的实证数据。

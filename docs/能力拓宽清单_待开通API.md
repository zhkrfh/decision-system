## 二、P0 · 最高优先（解锁核心业务）

### 1. 大模型 API（最关键的一项）

**为什么必需**：本机 3.9 GB 内存**无法本地跑模型**（7B 权重就要 4-14 GB）。这是绕过硬件限制的唯一路径。

**建议方案**（选一个）：

| 方案 | 优势 | 获取方式 |
|------|------|---------|
| DeepSeek | 国内直连，便宜，中文好 | platform.deepseek.com 注册 |
| 通义千问 | 阿里，额度充足 | bailian.console.aliyun.com |
| 智谱 GLM | 免费额度多 | open.bigmodel.cn |
| OpenAI | 生态最好，需代理 | platform.openai.com |

**配置方式**：
```
LLM_API_BASE=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxxxxxxx
LLM_MODEL=deepseek-chat
```

**验证命令**：
```bash
python tools/capability.py llm "用一句话解释凯利公式"
```

---

### 2. 语音转写 API（家史服务必需）

**为什么必需**：家史服务的核心是长时音频访谈转写。**本机内存做不了**（Whisper 本地版至少要 2 GB 内存，会 OOM）。

**建议方案**：

| 方案 | 说明 |
|------|------|
| 讯飞开放平台 | 中文转写质量最好，按分钟计费 |
| 阿里云智能语音 | 稳定，适合长音频 |
| OpenAI Whisper API | 便宜通用，$0.006/分钟 |

**配置方式**：
```
STT_API_BASE=https://api.openai.com/v1
STT_API_KEY=sk-xxxxxxxx
STT_MODEL=whisper-1
```

## 三、P1 · 放大获客

### 3. 小报童（专栏订阅）

- **用途**：专栏订阅，0.1% 分成费。比知识星球轻，适合起步
- **获取**：xiaobot.net 注册 → 微信登录
- **为什么现在不急**：没有订阅者前开通即空转。等算仓跑通后再开

### 4. 微信搜一搜 / 公众号模板消息

- **用途**：公众号内搜索优化、文章内预约入口
- **前提**：需要**微信认证号**（个人号无法开通）
- **判断**：值得做 —— 认证号还解锁 `stats` 接口（现在返回 48001）

### 5. 百度搜索资源

- **用途**：`站点/` 独立站 SEO 收录
- **获取**：ziyuan.baidu.com 添加站点
- **成本**：零，只需验证文件
- **为什么值得**：独立站是唯一完全自主可控的流量入口
